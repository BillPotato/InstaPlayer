How to use

  1. Install the InstaPlayer app on your phone.
  2. In the app's Settings, set the server address and the API key (ask the admin for the key), then Save.
  3. Wait until the status above reads Working. While it's Not working, imports are blocked.
  4. Open the Import tab, paste a Spotify playlist or album link, pick a quality, and start.
  5. Songs land on your phone as they finish and play fully offline — the server keeps no copy once your phone has them.
